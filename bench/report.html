Same-model methodology & interpretation
  • Claude Code 2.1.288 ran in bare mode (normal hooks, memory and CLAUDE.md discovery disabled), with empty skills/MCP lists. Built-in agents-md and plugin-authoring plugins still appeared in initialization events; their internal behavior was not audited. Megacode used isolated configuration with project instructions disabled and no installed skills/MCP connections. Native system prompts, tools and built-in features still differ—that is part of the harness/configuration being tested.
  • Same prompts, fresh workspaces, independent grader, one ChatGPT OAuth account, GPT-6 Astra, medium effort, CLIProxyAPI 8.0.13, and 300s process deadlines. Gateway configuration and measured source hashes were checked unchanged between attempts. Every recorded response model was gpt-6-astra.
  • Megacode spent 1,086.858s (99.14%) in model requests and 2.572s in tools. Eliminating all measured local tool time would save only about 0.23%. Prioritize avoiding unnecessary model round trips over parallelizing local reads alone.
  • Model timing includes request preparation, streaming and retries, not just inference. Claude’s native API time was 1,012.917s; its timing definition is not guaranteed identical.
  • Input totals use uncached + cache-read + cache-creation tokens for both harnesses. Megacode cache reads: 153,472; Claude: 73,856; included in totals, not additional. No cache-creation tokens were reported. Tokens are repeated context, not dollar costs.
  • Claude was faster in 11/15 matched task pairs and 4/5 suite repeats. The median paired task difference was 4.419s. Five repeats and uncontrolled cache/provider conditions do not establish a general advantage. This run is not directly comparable to older direct-backend or cross-model results.
  • Gateway use with non-Claude models is not officially supported by Anthropic. Custom-model context/output defaults, client retries, and other harness-specific behavior can differ. No Codex CLI rerun is included.

Methodology & interpretation
  • Claude Code 2.1.288 ran on October 3 using the claude-jach alias profile (~/.claude-jach), resolving opus to claude-opus-5-5 on the first-party backend, with medium effort. All tasks exited 0 with no timeouts. Completed total: 78.481s.
  • Claude input totals sum native result usage: 22 uncached + 23,801 cache-creation + 112,543 cache-read tokens = 136,366. Output: 7,925. Provider tokenizers and accounting differ; these counts are not directly comparable efficiency or cost measures. No transcript-length estimates were used.
  • Claude configured setting sources, hooks, slash-command skills, and MCP servers were disabled. Built-in plugins (including agents-md) remained present; auto-memory and instruction discovery were not explicitly disabled. This is a disclosed configuration difference, not a fully controlled comparison.
  • Three fixed smoke tasks exercise parsing/validation, atomic updates/immutability, and defect recovery from long tool output and source. The independent grader supplies 15 checks after agents exit. The unmodified baseline passes 1/15 checks and 0/3 tasks.
  • Megacode and Codex used gpt-6-astra with medium reasoning through the ChatGPT subscription / Responses API backend. Codex CLI version: 0.153.0. The megacode version was not recorded in the comparison.
  • These were sequential single runs: megacode first, Codex afterward, and Claude Code the next day. Cache warmth was not controlled. Use at least five alternating repeats and real repository tasks before drawing broader conclusions.
  • All completed runs used automatic approvals, without a sandbox, and a 300s process deadline. Megacode also had a 240s internal abort. No limits were reached; all agent processes exited successfully.
  • Codex ignored user configuration and execpolicy rules, disabled project instruction loading, and used ephemeral sessions. Other built-in defaults were retained.
  • Codex input includes 195,840 cached tokens. Megacode did not separately record cache usage. Token accounting includes repeated context and does not establish relative cost. Codex usage comes from native JSONL events, not inferred transcript length.
  • Megacode reported 22 model steps and 19 tool calls. Equivalent Codex counters were not reported; unavailable metrics are not zero.
